## 🌟 关于我

<p align="center">
  <img src="./image/about-me.jpg" width="100%" alt="About me" />
</p>

> “微光不必耀眼，只要曾照亮前行的路，便足以成为青春的方向。” ✨

我喜欢动手做项目：从日常学习中需要的小工具，到面向真实场景的 Web 应用；从 AI Agent 工作流，到单片机、传感器和嵌入式系统。我希望代码不仅能运行，也能真正解决问题。

- 🎓 **学校 / 专业**：合肥工业大学（HFUT）· 智能软件工程学院 · 软件工程
- 🤖 **关注方向**：AI Agent 与智能应用、软件系统开发、算法实践、嵌入式与软硬件结合
- 💻 **开发经历**：Python、C / C++、Java、Go、JavaScript / TypeScript、Web 前后端开发
- 🔧 **动手实践**：STM32、STC8、OLED、传感器与控制模块、Windows 桌面程序
- 🎮 **个人兴趣**：棋类与策略游戏开发、《第五人格》赛事及对局分析、校园实用工具
- 🚀 **我在坚持**：把课内知识用于课外项目，做好文档、尊重协作、持续完善作品
