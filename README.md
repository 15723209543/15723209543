## 📌 个人项目

### 🤖 嵌入式与竞赛实践

- [安徽省机器人大赛驱动与控制赛道程序](https://github.com/15723209543/Anhui-Provincial-Robot-Competition---Drive-and-Control-Track---program)  
  围绕电机、舵机、传感器与显示模块完成驱动与控制系统开发、调试与比赛实践。

  基于 STM32 与常用外设实现交互式校史展示，是嵌入式开发与硬件控制实践项目。

### 🏫 课程设计、校园系统与学习资源

- [校园水电煤气管理系统](https://github.com/15723209543/HFUT-Campus-Utility-Billing-Management-System)  
  基于 C++ 面向对象设计，实现信息录入、费用计算、缴费与欠费查询等功能。

- [合肥工业大学宣城校区校园导游咨询系统](https://github.com/15723209543/HFUT-navigation-system-with-dijkstra-algorithm)  
  基于 C++、带权无向图与 Dijkstra 算法实现地点查询、最短路径及多种限制条件下的路径规划。

- [HFUT 程序设计类课程资料网站](https://github.com/15723209543/HFUT-Programming-Course-Resources)  
  使用 HTML、CSS、JavaScript、Markdown 整理程序设计基础、数据结构、程序设计艺术与方法学及学习附录，支持本地离线阅读。

- [班级作业检查系统](https://github.com/15723209543/homework-submission-audit)  
  面向班级作业收集场景，对提交文件进行检查、问题分类与结果整理。

- [互助帮——大学生学习互助网站](https://github.com/15723209543/huzhubang-website)  
  围绕课程资料、学习答疑、学习搭子匹配与校园信息整理构建的学习互助网站。

### 🛠️ 工具、自动化与 Skill

- [DefenseAce 答辩助手](https://github.com/15723209543/DefenseAce-website)

- [数据结构实验生成工具](https://github.com/15723209543/HFUT-Data-Structures-Lab-Builder)  
  面向数据结构课程实验，组织代码工程、测试数据、实验报告、验收复习与最终打包流程。

  基于公开 GitHub 证据生成主页 README，并完成内容校验、图片隐私处理与 ZIP 打包。

- [人才与机会智能匹配](https://github.com/15723209543/match-talent-opportunities)  
  探索人才画像、岗位匹配、能力评估与发展建议等智能匹配场景。

- [证据矩阵检索研判 Skill](https://github.com/15723209543/evidence-matrix-research)  
  面向多源信息检索与研究任务，支持冲突识别、证据整合和可审计式结果整理。

### 🎮 游戏项目

- [棋奕六合一游戏平台](https://github.com/15723209543/chessgame)  
  整合多种棋类玩法，提供本地程序与网页端的综合棋类游戏平台。

- [跳棋游戏](https://github.com/15723209543/chinese-checker)  
  基于 C++17 与 EasyX 实现标准 121 孔跳棋，支持 2–6 人、连续跳跃、计时排名与机器人对局。

- [中国象棋](https://github.com/15723209543/xiangqi_game)  
  基于 C++17 与 EasyX 实现完整象棋规则，并接入 Pikafish 与 NNUE，支持机器人对战。

- [飞行棋游戏](https://github.com/15723209543/FlightChess-GAME)  
  基于 C++ 与 EasyX 实现多人飞行棋，支持计时、特殊棋盘规则、完整排名与机器人玩家。

- [重庆地图大富翁](https://github.com/15723209543/MonopolyGame_map-with-chongqing)  
  以重庆地图为主题设计的大富翁游戏项目。

- [一掷千金游戏](https://github.com/15723209543/OneThrowRich-game)  
  基于 C++17、EasyX、随机洗牌与启发式报价实现分轮开箱、报价决策与最终结算。

### 📈 第五人格与赛事分析

- [第五人格监管者首抓分析器](https://github.com/15723209543/Identity-V-First-Chase-Analyzer)  
  基于 C++17、EasyX、地图寻路与参数化模型分析监管者首追目标，并使用 Python 工具辅助处理地图与数据。
- [IVL 赛事排名分析与预测](https://github.com/15723209543/IVL_analyse)  
  基于 C++20、随机模拟、开放寻址哈希表与压缩状态精确穷举，对 IVL 赛事积分与最终排名分布进行分析。
- [IVTI 第五人格人格测试](https://github.com/15723209543/IVIT_test_project)  
  基于 Java、Swing / AWT 与 IntelliJ IDEA 开发，通过 20 道实战情景题计算四维倾向并生成 16 型人格报告，支持 PNG 导出。
